# AudioSpectGraphic

音からビジュアルをつくるツール（Mon Takanawa サウンドビジュアル展 出展作品）

https://0may-hub.github.io/spectgraphic/

オリジナル曲（約1分・くり返し）が流れ、そのオーディオスペクトラムから、曲の展開に合わせてビジュアルが自動でつくられていきます。
好きな瞬間で「とめる」→ タイトルを付けて、保存・投稿。

- `index.html` … ツール本体
- `song.m4a` … 曲（`src/song.js` で書き出したもの）
- `v1/` … 以前の版（音をあつめて、自分で組み立てる版）https://0may-hub.github.io/spectgraphic/v1/
- `supabase/` … 投稿・ギャラリーのサーバー側
